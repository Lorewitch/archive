# Архив Лороведьмы: веб-приложение

Сборка от 13 ноября 2026 года для существующего GitHub Pages.

## Что добавлено

- Установка на главный экран/компьютер и запуск в отдельном окне через манифест с относительными `id`, `start_url` и `scope`.
- Иконки 192×192, 512×512 и безопасная для системной обрезки maskable-иконка 512×512. Основа — выбранная трикветра с открытой книгой из загруженного проекта. Иконки меню, вкладки и Apple сохранены.
- Сохранение интерфейса и компактных каталогов при первом посещении. В этой сборке это 57 ресурсов, около 3,43 МиБ без учёта сжатия при передаче. Все тексты заранее не скачиваются.
- Автоматическое сохранение открытых JSON-материалов и загруженных изображений; сохранение первого посещения до получения страницей управления service worker.
- Различимые состояния сохранённой копии и несохранённого материала. Офлайн-промах не превращается в пустой раздел. Есть повтор загрузки.
- Обновление по кнопке с сохранением текущего маршрута. HTML, CSS и JS активной версии остаются согласованы до её обновления; новая версия готовится отдельно и не прерывает чтение автоматически.

## Данные и совместимость

Работа остаётся полностью статической, без внешнего сервера и дополнительных зависимостей сайта. Новых внешних запросов не добавлено. Относительные пути поддерживают GitHub Pages в `/archive/` и публикацию в корне домена.

Запросы игровых JSON идут сначала в сеть, при сетевом сбое или ошибке сервера используется сохранённая копия. Успешная загрузка обновляет копию; повреждённый JSON её не затирает. Ответы 404/410 удаляют старую копию, чтобы удалённая запись не возвращалась из кэша. При длительном ожидании сеть прерывается через 6 секунд и проверяется сохранённая копия.

Кэши ограничены: до 240 динамических JSON-файлов и 300 изображений, плюс отдельный кэш интерфейса/каталогов. Ограничение считается по файлам, а не по мегабайтам. Старые записи вытесняются при записи новых; очистка данных браузером также удаляет офлайн-копии. Обновление версии сохраняет накопленные тексты, заменяя только оболочку и каталоги.

Service worker ограничен путём Архива. Другие проекты на том же домене, внешние адреса и индексы `data/bot_*` не перехватываются. Ссылки Альтер и оба её индекса сохранены.

GitHub Actions теперь собирает `sw.js` после данных, CSS/JS и версии кэша, затем проверяет актуальность сборки. Для локальной сборки достаточно прежних Python и Node.js, npm-пакеты не нужны.

## Проверки

- Валидатор исходников, данных, ссылок, иконок, манифеста и актуальности сгенерированного service worker.
- 27 автоматических проверок клиента и PWA: ссылки Альтер, фильтры, гонки загрузки, границы кэшей, установка, отказ хранилища, обновления, удалённые записи и работа без сети.
- В настоящем браузере: открытие каталога и книги, обновление по кнопке с сохранением маршрута, перезагрузка сохранённого материала при остановленном сервере, сообщение для несохранённого материала и успешная повторная загрузка после возврата сервера. При повторном отключении сервера «Путеводитель по Тейвату» открылся на китайском языке сразу со всеми тремя томами.
- Главная, каталог книг и чтение книги проверены в 63 сочетаниях (3 экрана × 21 размер): ширина от 320 до 3840 px, включая обе стороны точки переключения меню 1180/1181 px и горизонтальные экраны телефонов. Выхода содержимого за область чтения и битых загруженных изображений не обнаружено. Один замер каталога 1024×768 не дождался документа; повторное открытие успешно, ширина содержимого и прокрутки совпала (1008 px).
- Подсказка установки проверена в мобильном меню 320×568 и 667×375: диалог помещается по ширине, длинное содержимое прокручивается, закрытие возвращает фокус кнопке меню. На узком экране границы диалога: x=19…301, y=16…552; на горизонтальном — x=103,5…563,5, y=16…359.
- Все 1313 файлов `content/` и 1322 файла `data/` побайтно совпадают с исходным загруженным ZIP, в том числе оба индекса бота.

Установка средствами операционной системы на физических Android/iPhone и запуск отдельного окна на пользовательском ПК не проверялись в удалённом браузере. Доступность штатной установки определяется браузером и устройством; обычный сайт доступен независимо от установки.

## Уточнение интерфейса и исправление опубликованной страницы

В обновлении v2 установка, обновление приложения, офлайн-подсказки и статус сохранённой копии перенесены из бокового меню в «Об архиве». Их состояние сохраняется при переходах: возвращение на главную восстанавливает доступную установку и готовое обновление. Исходный текст об Архиве сохранён.

В опубликованном index.html 13 ноября обнаружены два блока с неразрешёнными маркерами Git рядом с манифестом и диалогом установки. Такие строки попадают в видимый текст и нарушают разбор head, что объясняет показанный скриншот. В исправленной сборке index.html чистый. tools/check_source.py проверяет исходники до сборки, основной валидатор повторяет проверку, сборщик PWA отклоняет конфликтный HTML, а service worker не сохраняет такую страницу при установке новой версии.

README.md переписан для посетителей по структуре актуального README «Угольного побега»: короткое вступление, ссылка, разделы и понятные инструкции. Техническая информация перенесена в MAINTENANCE.md.

Пройдены 29 тестов клиента/PWA и 3 Python-проверки обнаружения конфликтов. После замены версии в браузере проверены Ctrl+F5, переходы в каталог и обратно, отсутствие блока PWA в боковом меню и работа подсказки установки. Все 1313 файлов content/ и 1322 файла data/ совпадают с предыдущей сборкой, включая индексы Альтер.

Новый блок «Об архиве» дополнительно проверен на 21 размере от 320×568 до 3840×2160: переполнений и битых изображений нет. На 320×568 проверены прокрутка к установке и открытие диалога. При перезагрузке каталога показаны 10 записей, элементы PWA на этой странице отсутствуют.
