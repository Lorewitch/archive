# Аудит Архива Лороведьмы · 13 ноября 2026

## Что изменено

- Название проекта заменено на «Архив Лороведьмы»: заголовок вкладки, метаописание, меню, логотип, главная страница, документация и заголовки сборки.
- Для вкладки добавлены SVG и ICO с существующим символом Архива. Для сохранения на экран устройства добавлен PNG 180 × 180. Версия кэша обновлена для CSS, JS, логотипа и новых иконок.
- На мобильной панели теперь видно название Архива.
- Удалены старый табличный рендеринг каталога, недостижимые функции, вычисления для скрытых заметок, неработающие обработчики сворачивания описаний, невидимая полоса прокрутки меню и накопившиеся стили старых экранов.
- Удалены девять неиспользуемых изображений: семь прежних иконок элементов из `assets/icons/element/`, `ui/reputation_quest.webp` и `ui/stories.webp`. Действующие цветные иконки и белая подсветка выбранного типа оружия сохранены.
- Удалены ненужные `.gitkeep` внутри папок изображений. Оригиналы игровых материалов сохранены.
- Счётчики категорий получают данные из небольшого `archive_summary.json`: они больше не показывают ноль до первого посещения категории. Прежние числовые поля сводки сохранены, добавлено поле `groups`.
- Исправлено открытие другой книги, если выбранного ранее тома в ней нет: показывается её первый том.
- Наведение и открытие карточки используют один запрос. Ошибка загрузки допускает повторную попытку, кэш прочитанных записей ограничен 24 карточками.
- Отложенное обновление поиска не вмешивается в открытую читалку. Упрощены обработчики изменения размеров окна.
- Длинные названия добычи переносятся внутри карточек противников. Исправлены формы слова «запись» в счётчиках.
- Мобильное меню корректно исключает закрытую панель и содержимое под открытым меню из клавиатурного фокуса. При смене мобильной и настольной раскладки состояние меню синхронизируется.
- Добавлены учёт безопасных полей экрана, управление прокручиваемыми фильтрами и вкладками с клавиатуры и режим уменьшенного движения.
- GitHub Actions реагирует на изменения HTML и готового CSS, проверяет JavaScript и запускает восемь регрессионных тестов. Валидатор дополнительно проверяет иконки вкладки, счётчики категорий и индексы Альтер.

## Проверки

- Полная пересборка данных из Markdown: 105 книг, 61 набор артефактов, 234 записи оружия, 251 запись инвентаря, 385 историй, 257 противников — всего 1293 карточки.
- Все исходные файлы `content/`, включая 1293 Markdown-файлов, побайтово совпадают с приложенным проектом. Все игровые JSON, кроме сводки со счётчиками категорий, также неизменны.
- Готовые CSS и JS совпадают со сборкой из исходников. Проверка синтаксиса JavaScript и основной валидатор пройдены.
- Восемь автоматических тестов: маршруты Альтер, смена книги, объединение и повтор запросов, ограничение кэша, гонка при смене категории, фильтры персонажей и оружия, первоначальные счётчики, экранирование текста.

- Дополнительно вручную проверены поиск, фильтры «Ведьмовство» и «Звёздный клин», белая подсветка оружия, переход из мобильного меню, китайский текст и чтение нескольких томов подряд.
- Все 1420 оставшихся файлов изображений и иконок имеют ссылки из текущих данных или интерфейса; отсутствующих локальных ассетов не найдено.

## Связь с Альтер

- Сохранены существующий адрес GitHub Pages и все 1036 маршрутов бота. Оба исходных индекса сохранены без изменений.
- Полная пересборка индексов отдельно проверена: получены те же данные и версия `bot_mentions:b77af110011c`.
- Настоящий модуль поиска из приложенной версии Альтер загружает компактный индекс: 1036 записей и 29 169 обработанных пассивных фраз из 31 237 исходных фраз.

- В сборку добавлена проверка целостности связи: состав карточек, пути к данным, маршруты, поисковые связи, согласованность полного и компактного индекса. Ошибки останавливают сборку.
- Файлы бота и его настройки не изменены; переустанавливать Альтер не требуется.
